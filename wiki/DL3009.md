# DL3009

**Severity:** Info

## Description

Delete the apt lists (/var/lib/apt/lists) after installing something

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
RUN apt-get update && apt-get install -y nginx
```

### Good

```dockerfile
RUN apt-get update && apt-get install -y nginx && rm -rf /var/lib/apt/lists/*
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3009
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3009
FROM image
```
