# DL3004

**Severity:** Error

## Description

Do not use sudo as it leads to unpredictable behavior. Use a tool like gosu to enforce root

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
RUN sudo apt-get update
```

### Good

```dockerfile
RUN apt-get update
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3004
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3004
FROM image
```
