# DL3023

**Severity:** Error

## Description

`COPY --from` cannot reference its own `FROM` alias

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
# Example that violates DL3023
```

### Good

```dockerfile
# Example that follows DL3023
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3023
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3023
FROM image
```
