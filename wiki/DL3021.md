# DL3021

**Severity:** Error

## Description

COPY with more than 2 arguments requires the last argument to end with /

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

### Bad

```dockerfile
# Example that violates DL3021
```

### Good

```dockerfile
# Example that follows DL3021
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3021
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3021
FROM image
```
