# DL3001

**Severity:** Info

## Description

For some bash commands it makes no sense running them in a Docker container like `ssh`, `vim`, `shutdown`, `service`, `ps`, `free`, `top`, `kill`, `mount`, `ifconfig`

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
RUN ssh user@host
```

### Good

```dockerfile
RUN echo "Use appropriate tools for containers"
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3001
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3001
FROM image
```
