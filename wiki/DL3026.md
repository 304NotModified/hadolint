# DL3026

**Severity:** Error

## Description

Use only an allowed registry in the FROM image

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
# Example that violates DL3026
```

### Good

```dockerfile
# Example that follows DL3026
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3026
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3026
FROM image
```
