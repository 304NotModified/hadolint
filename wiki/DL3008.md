# DL3008

**Severity:** Warning

## Description

Pin versions in apt get install. Instead of `apt-get install <package>` use `apt-get install <package>=<version>`

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
RUN apt-get install -y nginx
```

### Good

```dockerfile
RUN apt-get install -y nginx=1.18.0-0ubuntu1
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL3008
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL3008
FROM image
```
