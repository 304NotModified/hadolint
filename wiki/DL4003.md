# DL4003

**Severity:** Warning

## Description

Multiple `CMD` instructions found. If you list more than one `CMD` then only the last `CMD` will take effect

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
# Example that violates DL4003
```

### Good

```dockerfile
# Example that follows DL4003
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL4003
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL4003
FROM image
```
