# DL1001

**Severity:** Ignore

## Description

Please refrain from using inline ignore pragmas `# hadolint ignore=DLxxxx`.

## Rationale

This rule helps ensure Dockerfile best practices and avoid common mistakes that can lead to:
- Security vulnerabilities
- Larger image sizes
- Unpredictable behavior
- Maintenance difficulties

## Examples

### Bad

```dockerfile
# Example that violates DL1001
```

### Good

```dockerfile
# Example that follows DL1001
```

## Configuration

To ignore this rule, add it to your `.hadolint.yaml`:

```yaml
ignored:
  - DL1001
```

Or use inline ignoring:

```dockerfile
# hadolint ignore=DL1001
FROM image
```
